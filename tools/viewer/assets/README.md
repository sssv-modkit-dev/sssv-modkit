# Viewer branding

`icon.png` is the owner's requested blue bear-head branding, recreated using
the viewer's **Save icon PNG** control on 2026-10-29. It is a transparent
256×256 PNG, embedded locally in the generated page as both favicon and brand
image. No `.ico` file is needed.

The render uses the crazy-bear head part, the recolours from `configs/bear.json`,
and an additional `000000FF` → `FCFCFC` recolour for the pale eyes. Select the
head, choose Right, then use the curved-arrow controls to turn it upright
before exporting. No patched ROM is needed for this workflow.

This small raster image contains third-party game imagery. See `NOTICE.md`;
it is not included in the project's CC0 dedication. Original ROMs, model data,
and other render captures are kept outside the published source tree.
