Optional Python bridge

The bridge saves working files on your computer and uses the local Python tools to build a ROM. It is a developer tool and needs the project's Python tools, Pillow and NumPy. From your local editor checkout, run:

python tools/story_editor.py

Then open this editor on the local bridge. Check again works when this page is served by that bridge.

How to edit dialogue

Load your ROM, choose a message group, then select a line. Edit its text and watch the space budget. Download edits JSON for a backup. Return to the guided build to combine changes, or use Save & build ROM for dialogue and painted ground sheets. Check message timing in game.

Advanced: text codes and limits

The budget counts two bytes per character (including line breaks), four per string and two for the count. Shorten another line in the same group to free space.

Hold times apply to individual script records; a line can appear more than once. Timing changes have disk round-trip validation only; check the pacing in game.
