The three emulator captures only have black frame borders cropped. No game
objects, colours, HUD elements, or results were generated or retouched. They
retain their source pixel scale: 1875 × 672 for the bear comparison and
305 × 224 for each prototype frame. The bear comparison is retained only as an archived file, not displayed as evidence.

The original level viewer browser capture was resized proportionally from 1440 × 960 to
1200 × 800 and saved as a JPEG. The updated `parts-lab.jpg` is an unretouched
1384 × 805 JPEG captured directly from the current public-build Model Editor in Chrome
on 2026-11-14, in Dracula theme. The owner requested its replacement for public
documentation. It shows the visible browser viewport, with scrollable panels.
`parts-lab-before-after.png` is six headless-Chrome captures (1400 × 900 window) of
the 3D view only, cropped to 800 × 720, scaled to 400 × 360 and tiled 3 × 2. Nothing
was retouched. It still needs the owner's approval like the images above.
The level viewer capture is documentation imagery only; its embedded game data
and generated HTML remain private.
