# Guided build

Open [Guided build](https://sssv-modkit-dev.github.io/sssv-modkit/start.html) from Home.

1. Choose your own unzipped US 1.0 ROM, or continue without a ROM to explore sample content. A remembered ROM loads automatically. Without a ROM, building is disabled.
2. Choose **Patch only** for bugfixes and quality of life, or **Mod in depth** to visit the editors. All nine listed patches are coming soon and disabled. With no patches available, Patch only builds an unchanged copy and excludes saved editor changes.
3. In Mod in depth, visit Models, Textures & Tilesets, Levels and optional Dialogue. Each step can be skipped. Use **Back to guided build** to return. Edits are remembered automatically in this browser, matched to the shared source ROM.
4. Review the saved changes, then choose **Build ROM**. Mod in depth combines saved model, level, dialogue and ground tile changes. Download IPS or ROM, or choose **Play this build** and press Play.

Building keeps the source ROM unchanged. Verify the result in game; browser emulation is experimental. Unsupported edits, conflicting byte changes, source mismatches and writer limits can stop a build with an error. Save edit files as backups. **Forget ROM** clears the shared source, saved editor changes and the guided build on this device.

Nothing is uploaded. Runtime files load from this site's own origin; see [Network](../NETWORK.md). Phone editors provide touch controls and scrolling panels; build speed and emulation performance depend on your device.
