# Guides

Start with [Getting started](guides/GETTING-STARTED.md). It follows the guided build from your ROM to a playable build. No Python setup is needed for this browser path.

| Step | Guide | What you can do |
| --- | --- | --- |
| Start | [Getting started](guides/GETTING-STARTED.md) | Load a ROM and choose a build path |
| 1 | [Models](guides/MODEL-EDITOR.md) | Recolour and reshape parts; paint supported eye textures |
| 2 | [Textures & Tilesets](guides/TEXTURES-TILESETS.md) | Paint ground tiles and check seams |
| 3 | [Levels](guides/LEVEL-EDITOR.md) | Move, add and change stage objects |
| 4 | [Dialogue](guides/DIALOGUE.md) | Change messages and their timing |
| Finish | [Play](guides/PLAY.md) | Run or download your build |

You can skip any editor. Keep downloaded edit files as backups. Browser storage can be cleared by your browser or by **Forget ROM**.
