Local ROM

ROM bytes are read locally. Loading a game downloads EmulatorJS 4.2.3 and its emulator core from cdn.emulatorjs.org. That third-party code runs in this page. Internet access and WebGL are required.

Choose a ROM to begin. Browser emulation is experimental; SSSV compatibility and performance need testing.

Use the emulator's controller settings to see or change keys, connect a gamepad, or enable touch controls. Click inside the game to focus it. Use its menu for fullscreen, saves and screenshots.

Parts Lab exports edit JSON, not a playable ROM. Build your patch with the local modkit, then select the resulting ROM here. Level editing remains a private prototype.
