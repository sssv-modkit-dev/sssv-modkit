Message timing

Pauses between events (advanced)

Each level runs a script: show a message, move the camera, wait, open a door, and so on. These are its waits. Make a number smaller to shorten a gap (for example a slow cutscene), larger to hold it longer, 0 to skip it. 30 frames is about 1 second. Each wait lists the message lines just before and after it, so you can tell where in the level it happens.

Advanced: text codes and limits

The budget counts two bytes per character (including line breaks), four per string and two for the count. Shorten another line in the same group to free space.

Hold times apply to individual script records; a line can appear more than once. Timing changes have disk round-trip validation only; check the pacing in game.
