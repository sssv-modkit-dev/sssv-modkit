# Contributing

Feel free to use this however you like.

You are also free to contribute and make changes, if you can manage to navigate around this maze of AI-generated documentation. Work on your own branch or fork, and open a Pull Request if you want your changes in the main repo.

See the [Code of Conduct](docs/CODE_OF_CONDUCT.md).

## How to contribute

1. **Fork** <https://github.com/sssv-modkit-dev/sssv-modkit> on GitHub (or, if you have write access, skip to step 3).
2. **Clone your fork:**
   ```sh
   git clone https://github.com/<your-username>/sssv-modkit.git
   cd sssv-modkit
   ```
3. **Create a branch** off `main`, and keep `main` clean for syncing:
   ```sh
   git checkout -b my-change
   ```
4. **Make your changes** and run the tests in `tests/` before committing.
5. **Commit** with a short, clear message, then push your branch:
   ```sh
   git commit -am "Describe the change"
   git push -u origin my-change
   ```
6. **Open a Pull Request** from your branch (or fork) against this repo on GitHub. Say what you changed and why.

## Notes

- Do not include game ROMs or other copyrighted game data in commits or PRs. Bring your own ROM.
- Docs live in `docs/`; start with `README.md`.
